## 💖 Features That Will Melt Her Heart

- **Silky Smooth Animations:** Built with `framer-motion` for a cinematic, immersive storytelling experience. From floating sticky notes to buttons that mischievously run away when you try to click "No".
- **Glassmorphism Aesthetic:** A premium, modern UI featuring a soft pink color palette, blurred frosted-glass backdrops, and custom CSS shines that make the page feel alive.
- **Dynamic "Love in Numbers":** Automatically calculates and updates the exact number of days since we started talking (April 19th, 2026)—updating automatically every single day!
- **Interactive Love Agreement:** A beautifully styled "Official 'Ohana Love Agreement" certificate that she can natively download straight to her phone as a high-quality image.
- **Silent Email Notifications:** Instantly dispatches an email to my inbox via `Web3Forms` the exact moment she clicks "YES!" (or double-confirms "NO" 💔), completely invisibly in the background.

## 🛠️ Technical Stack (The Magic Under the Hood)

This isn't just a cute page; it's a fully modernized, highly responsive web application built with cutting-edge tools!

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router & Server Components)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (Because only the latest and greatest for her!)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** `lucide-react`
- **Client-Side Image Generation:** `html-to-image` (For generating the downloadable Love Agreement snapshot natively on the client without a backend).
- **Audio:** `howler.js` (For seamless background romantic vibes).
- **Notifications:** `Web3Forms` (For serverless, frictionless API-based email dispatching).

## 🚀 How to Run the Magic Locally

1. **Clone & Install Dependencies**
   ```bash
   pnpm install
   ```

2. **Set up Environment Variables**
   Create a `.env.local` file in the root directory and add your Web3Forms access key (so you get notified when she answers!):
   ```env
   NEXT_PUBLIC_WEB3FORMS_KEY=your_access_key_here
   ```

3. **Start the Development Server**
   ```bash
   pnpm run dev
   ```

4. **Experience the Love**
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the magic. Best experienced with the volume turned up! 🎶
